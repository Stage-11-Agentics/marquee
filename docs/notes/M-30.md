# M-30 — Sessionize import

Marquee's Sessionize importer accepts a sessions CSV and a speakers CSV, shows a
write-free mapping preview, and then reconciles the export into the selected
conference. Matching sessions use `external_ref`; speakers use normalized email
with a name fallback. The importer retains speaker relationships, canonicalizes
Sessionize `undecided`/pending vocabulary to `in_review` while retaining the raw
value in the import row reason, records evaluation scores and comments, and
represents external headshots as pending `person_headshot` attachments rather
than fetching them during an import.

Every run writes `imports` and `import_rows` outcomes. A second run of the same
export updates/skips the existing rows instead of creating duplicates. Undo walks
the import's own snapshots, restores matched records, removes only import-owned
rows, and retains the R2 manifest for audit. Seeded people, submissions,
participations, and evaluations are not removed by an undo.

The importer creates a closed Sessionize form for custom fields and stores the
values as submission answers. This note is the implementation record; MRQ-40 / M-45
owns the README fold.

AC-109 remains an operator-assisted check: a real Sessionize export containing
sessions, speakers, and evaluation results is required to verify these fixture
column names and status vocabulary against reality.
