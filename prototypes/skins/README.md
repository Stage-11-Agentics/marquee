# Marquee — Skin round (program home)

Three visual languages, one screen. `skin-a.html` · `skin-b.html` · `skin-c.html` — each self-contained, light-mode primary, open from `file://`. Content, hierarchy, and implied interactions are copied verbatim from `prototypes/pipeline-v1.1/index.html` `#dashboard`; only the visual system changes. Each file opens with its liftable token block.

- **A · House Lights** — the program home is a theatre call board: an ink masthead, a bone playbill, serif display heads over grotesque figures, and the track palette running as a light bar across the pipeline, so the name Marquee earns itself.
- **B · Press Room** — the tool that respects you feels made of paper: warm stock, humanist type, letterpressed numerals and cards that sit on the desk rather than float above it, so a day of chase work reads as craft instead of admin.
- **C · Flight Deck** — the ops person's cockpit in daylight: a hairline instrument grid, monospaced figures and micro-labels, zero shadow and zero ornament, so every number reads like a gauge and the whole panel can be scanned in one pass.
