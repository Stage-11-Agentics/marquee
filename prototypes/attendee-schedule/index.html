For agents

  
Everything on this site is anonymous, typed JSON. An agent can build its human's conference schedule end-to-end without a browser:

  
GET  /api/v1/public/agenda?event=aie-nyc-2026
      → the full published program: sessions, times, rooms,
        buildings, tracks, formats, speakers

POST /api/v1/public/schedules
      { "eventSlug": "aie-nyc-2026",
        "sessionIds": ["ses_…", "ses_…"] }
      → { "code": "MQ-K7TQM3RA", "writeKey": "…",
          "urls": { "share": …, "sync": …, "webcal": …, "ics": … },
          "overlaps": [] }

GET  /api/v1/public/schedules/MQ-K7TQM3RA
      → the set with full session objects + computed overlaps

PUT  /api/v1/public/schedules/MQ-K7TQM3RA
      (X-Schedule-Write-Key header) → replace the set

  
Building a schedule counts toward the session demand signal (anonymously).

  
Driving the UI instead? Every session card carries stable hooks: data-public-session-id / -slug / -start / -end / -day.
