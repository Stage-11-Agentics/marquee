# Direction: The Chase

**Read `prototypes/PROTOTYPE-CONTRACT.md` first — it is binding. This file is what makes your take different.**

## Core assumption

The center of gravity of a conference program is **post-acceptance operations**. The primary user is the ops coordinator getting 150 humans on stage; the CFP and agenda exist, but the heartbeat is the chase — tasks, comms, deadlines, "who is behind?" The product that wins is the one open on the coordinator's second monitor all day.

## Home surface

The **real-time chase board**: every accepted speaker × every task, live completion states, sorted by how-far-behind. Filters (overdue / incomplete / by task type / by track) as fixed chips. One-click templated nudge to any filtered set, with the send recorded inline. A completion sparkline per wave. Everything else — submissions, review, agenda — is one click away in a slim rail, but the board is home.

## Signature moves (must actually work)

1. **The board itself**: filter to overdue, select the stragglers, "Send reminder (23)" — a compose drawer with a template and merge-field preview, sending logs inline per row.
2. **Command palette (⌘K)**: find any speaker/abstract/session by name from anywhere, jump straight to it.
3. **A speaker drawer**: click any row → side drawer with their tasks, message history, sessions, bio — chase context without leaving the board.

## Aesthetic & voice

**Control-room utility.** Dense but never cramped; row-first layouts; muted surface with strong status color semantics (overdue amber, done green, at-risk red used sparingly); monospaced tabular numerals for counts and dates; instant transitions, zero decorative motion. Voice: operational and calm — "9 speakers behind on headshots. Nudge them?" The tool respects that the user is busy.
