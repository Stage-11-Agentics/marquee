# KYS-1: Landing and public-agenda demo doors point at the wrong rooms

Found in KYS judge-path QA (Aditya + Claude), local run 2026-08-11. Two public doors misdirect: 'View public CFP' on the landing went to /submissions (organizer admin, a sign-in wall for a signed-out judge) instead of the public form at /f/cfp; and the public agenda header's 'Organizer demo' points at /submissions?demo=organizer, which performs no auth outside the landing page (nothing in src reads ?demo=), so a signed-out visitor lands on the 401 screen. Fix in the linked branch: the CFP door opens /f/cfp; the agenda's demo door opens / (the landing, where the demo buttons actually authenticate). The speaker door's 403 dead end was fixed upstream in parallel (landing now sends it to /portal?demo=speaker) and is not part of this change.
